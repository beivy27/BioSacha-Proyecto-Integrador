## Descripción del proyecto

BioSacha es una aplicación móvil orientada al registro y gestión de información botánica, desarrollada como parte del proceso académico de Aplicaciones Móviles.

El proyecto integra una aplicación móvil desarrollada con React Native y Expo, conectada con un backend mediante servicios API REST, incorporando autenticación, persistencia local, sincronización de información y gestión segura de registros.

## Objetivo

Desarrollar una solución móvil que permita gestionar registros botánicos de manera segura, considerando escenarios con conectividad limitada mediante almacenamiento local y posterior sincronización con el servidor.

## Arquitectura del sistema

El proyecto está compuesto por dos módulos:

### Mobile

Tecnologías:

- React Native
- Expo
- TypeScript

Características:

- Registro botánico.
- Persistencia local.
- Manejo de permisos nativos.
- Sesión segura.
- Sincronización con backend.

### Backend

Tecnologías:

- Node.js
- API REST
- Prisma ORM

Características:

- Gestión de usuarios.
- Autenticación.
- Administración de registros botánicos.
- Persistencia de información.
